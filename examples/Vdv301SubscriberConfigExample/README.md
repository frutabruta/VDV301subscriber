# Vdv301SubscriberConfigExample
More developed example using the VDV301subscriber library, based on the Minimal example.
Can be set up using settings.ini file
Different setting file can be specified by launching with a --config parameter.

Following can be set:
- Service name
- Structure name
- Reply port
- Reply path
- Service type

App restart is needed between parameter changes.
